# finfreedom 项目章程

**版本：** 1.0（初始）
**日期：** 2026-10-29

## 目标

把原 Financial Freedom 项目的信息查询、信息获取、确定性投研工具、受限个人资料操作、MCP 和 Skills 重建为名为 finfreedom 的 DSH 可安装插件。finfreedom 面向国内用户，产品名称及相关商标归利长安（lichangan.com）所有。DSH 负责 Agent 循环、模型调用、会话与工具调度。本仓库不承载旧 Financial Freedom 页面、DeerFlow worker 或自研 Agent 主循环。旧用户数据不迁移，新实例从空库开始。

## 不可违反的原则

1. **同一能力，同一数据语义。** 插件、MCP 和可选 API 共享一套业务服务及数据契约；不得分别实现出不同的金额、时点或权限规则。
2. **证据先于解释。** 行情、财务、新闻、基金披露、账户与研究结果必须携带来源、源时间、采集时间、单位、币种、覆盖与新鲜度；缺失数据明确返回缺口。
3. **确定性计算。** 指标、估值、资金统计和回测由代码计算；模型只负责选择工具和解释结果，不得补造数值。
4. **账户身份由运行时绑定。** `owner_id`、会话与账户范围不得由模型参数选择；每次账户读取和写入都经过可信身份与权限边界。
5. **交易隔离。** MCP/DSH 工具不提供真实或模拟下单、撤单、改交易凭据、解锁交易、扩大授权的路径。保留原项目可读交易记录，不将记录读取解释为交易授权。
6. **默认本地与最小权限。** 凭据不入 Git、不进模型上下文和普通日志；新产生的用户资料与数据卷须可备份、可删除、可随部署移动。第三方 Skill 与 MCP 内容作为不可信数据处理。
7. **可安装、可卸载、可复现。** 插件安装应显式声明运行依赖与版本，验证 DSH profile 中的真实挂载；卸载不自动删除用户数据。安装不能悄悄覆盖其他插件配置。
8. **独立运行。** 完成态不得依赖旧 `financial-freedom` 进程、源码目录、DeerFlow 包或旧网页服务；不读取其数据卷。

## 变更门槛

- 新增或删减工具、资源、写操作、数据源时，先更新 `capability-inventory.md`、`contracts.md` 与对应验收场景。
- 存储格式升级、权限模型、交易边界发生变化时先更新本章程与规格，再实现。
- 上游公共数据源或 DSH API 变化时记录版本、降级行为与兼容测试；不得静默把旧缓存标作实时。
