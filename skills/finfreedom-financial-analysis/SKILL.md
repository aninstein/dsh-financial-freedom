# 财务与估值研究

结合 `finfreedom-research` 使用：先确认公司代码、市场与报告期，查询 catalog 中的 `get_stock_financials`、`get_stock_dossier` 和文档工具。利润表、资产负债表与现金流量表应匹配报告期、币种、单位及合并范围；区分年度、单季和累计值。计算增长、利润率、经营现金流、负债或估值指标时列明公式与可验证的分子分母。

关注利润与现金流背离、应收与存货、债务期限及一次性项目，说明行业口径差异和反证。估值或敏感性分析须给出依据、情景假设和适用边界；缺少财务数据、可比对象或可靠价格时明确写明，禁止凭模型记忆补数或臆造目标价。引用报告、页码或来源及发布日期。
